## 实现内容

1. 显示标准 8×8 初始棋盘，32 枚棋子、a–h/1–8 坐标、当前走棋方、状态提示。每个格使用稳定的 data-square="e2" 等实际坐标。
2. 点击当前方棋子显示合法目标；点击目标调用 session.tryMove。支持重新选子、取消选择。点击走棋可靠完成后再考虑拖动，拖动不是本任务必需。
3. 升变弹窗选择后/车/象/马，能够取消；选定前棋局不变。
4. 显示最近一着、将军、将死、逼和及其他终局理由；所有合法性和结局以快照为准。当前可申请和棋时显示申请操作，调用 claimDraw。
5. 实现“悔棋”“重置棋局”“翻转棋盘”；翻转只改变显示。终局后仍可悔棋或重开。按钮禁用状态应符合 canUndo 和 outcome。
6. 显示 SAN 棋谱，以白黑回合成对排列；最后一着可见。
7. 提供收纳在“局面工具”区域的 FEN 输入/载入和当前 FEN 复制功能。用 session.reset({fen})，错误时保留当前棋局并显示原因。剪贴板不可用时提供可选中的文本。
8. 临时棋子使用 Unicode 国际象棋符号或带明确标识的纯 CSS 方案。白黑双方与六种棋子必须易于区分。将棋子渲染集中在一个可替换模块，之后换成 PNG/WebP 不应改规则。

## 文字视觉规格

参考布局是浅色大棋盘、简短的顶部提示和充足留白。顶部无需人物插画。桌面棋盘与操作/棋谱区域合理排列，窄屏将操作区移到棋盘下方。棋盘始终正方形，320px 宽屏幕不能出现横向溢出；坐标、提示、升变弹窗不能遮挡操作。

采用白/浅灰棋格、柔和绿色操作与合法目标提示、淡紫色重点提示。保证白棋在白格上可辨认；不要堆叠过度装饰。使用本机字体、临时棋子符号，不下载外部素材，不要求模型理解参考图里的非文字细节。

保持现有 CSP，不加入 unsafe-inline/unsafe-eval。CSS 保持独立文件，通过 HTML link 加载。不要新增依赖、远程 API、Stockfish 伪实现、联网房间或保存系统。

## 自动化验收

你可以编写和运行 Playwright，通过脚本点击和输入。默认配置使用本机 Edge，无需人工操作。至少验证：

- 开局 32 枚棋子，e2-e4 后轮到黑方；非法 e2-e5 不改变棋局。
- 黑方应手后悔棋，局面、棋谱和轮到谁同步恢复。
- 翻转后从实际坐标继续正确走棋；重开恢复标准布局。
- 用 FEN `7k/P7/8/8/8/8/8/7K w - - 0 1` 验证升变先弹窗、取消不落子、选择马后棋子类型正确。
- 用 FEN `7k/6Q1/6K1/8/8/8/8/8 b - - 0 1` 验证将死结果，重开仍可走棋。
- 无效 FEN 不破坏当前局面；320px 窄屏无水平溢出。
- 浏览器无 pageerror，保持可见按钮名称和实际坐标等稳定定位方式。
